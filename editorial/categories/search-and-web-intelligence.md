A search API built for a results page returns titles, links, and a short snippet. The agent then has to fetch the page, strip the layout, and guess which source was worth opening. This collection is for retrieval that tries to hand back something a model can quote or reason over: a cleaned page, a docs lookup, a cited passage, or a research pass.

Exa, Tavily, Linkup, Parallel, and SerpKite are search APIs positioned for agents. Jina Reader is the pattern of turning a URL into model-friendly text. Jina DeepSearch is the multi-step research API beside it. Context7 is specifically current library documentation. ProofFetch is about pages an agent can cite. ReleaseLog is a verified calendar of AI releases, published separately from this catalog. NotHumanSearch is an index of services for agents. A web search API, a docs index, and a citation store do not answer the same question, even when they sit in one table.

Judge the output, not the word "search." Does the response include the source URL and enough text to use, or only a rank and a title? Can the agent ask for one page rendered as text, or only a query? Freshness and depth are documented by each vendor. This catalog does not score them against each other. Clicking through a logged-in application is a browser problem. Paying per request is a commerce problem. Both show up next to search, and neither is solved by a cleaner snippet.
