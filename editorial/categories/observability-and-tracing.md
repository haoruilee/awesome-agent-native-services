A traditional trace answers whether a request was slow. An agent run is a chain of model calls, tool calls, and retrieved text, and the useful question is which of those sent the next step wrong. CPU charts do not show that. This collection is for trajectory traces, evaluation, and replay aimed at the chain.

Langfuse, Laminar, OpenLIT, AgentOps, Braintrust, Galileo, and LangWatch mix tracing and evaluation, some as open-source collectors and some as hosted products. The dossiers are the place to see which is which. AgentSight is described as system-level observability. agent-inspect and Agent Trace are smaller, closer to the code that emitted the run. OrcaReplay is about replaying a failure later. AgentEvals is framed as scoring agents before they are in production. numbat is endpoint visibility into agent activity, with optional blocking described in its own docs. Overlap is normal. The report is not.

A useful record names the tool, the context that was inserted, and the output that followed. An evaluation set tells you whether a change helped, and only if you trust the cases. Replay lets someone walk a bad night again. None of those stop a tool call that should not have happened. That is an oversight gate, or a policy on a gateway. Read the product docs for what is stored, and for how long, before sending production prompts to a third party.
