## What it does

Lets agents join live meetings, process media streams, and execute conversational workflows in real time.

## Agent-facing interfaces

- **Catalog protocols:** REST, webhook, SDK
- **MCP:** ⚠️ No standalone official MCP server package.
- **Agent Skill:** ⚠️ No official AgentSkills package found.
- **Onboarding type:** `other`

## Protocol surface

REST APIs, Python SDK, WebRTC transports, webhooks.
