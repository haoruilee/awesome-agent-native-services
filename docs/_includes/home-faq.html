{% capture faq_q1 %}What is an agent-native service?{% endcapture %} {% capture faq_a1 %}A service designed from the ground up for AI agents as first-class consumers, or a purpose-built surface for operating live agent systems. Admission requires all five hard criteria: agent-first positioning, agent-specific primitives, an autonomy-compatible control plane, a machine-to-machine integration surface, and agent identity or delegation semantics. Human products that later add an agent layer do not qualify.{% endcapture %} {% capture faq_q2 %}How does an agent join?{% endcapture %} {% capture faq_a2 %}The gold standard is URL Onboarding: the agent reads a machine-readable document and follows the instructions — no SDK install, dashboard, or human-issued API key required for the join sequence.
